# Руководство пользователя и разработчика: OPM-Synth Studio

**OPM-Synth Studio** — программный комплекс для генерации трехмерных синтетических геолого-гидродинамических моделей нефтяных пластов и подготовки датасетов для машинного обучения (3D CNN, суррогатное моделирование, Physics-Informed ML).

---

## 1. Назначение и возможности комплекса

Комплекс решает задачу создания представительных ансамблей геологических моделей на основе базовой колоды месторождения:
- **Сохранение вертикальной связности пласта**: трехмерная спектральная геостатистика исключает искусственное расслоение пласта по глубине;
- **Согласованная петрофизика**: совместная ко-симуляция проницаемости ($K_x, K_y, K_z$) и пористости ($\Phi$) с сохранением уравнения Козени-Кармана и седиментационной анизотропии;
- **Двухфазная гидродинамика**: моделирование работы 13 скважин месторождения с расчетом профилей дебитов нефти и обводненности;
- **Промышленный экспорт**: формирование валидных текстовых колод Eclipse / OPM Flow (`.DATA`, `.INC`) и 4D тензоров NumPy (`.npz`) для обучения нейросетей.

## 2. Установка и быстрый старт

### Требования
- Python 3.9+
- Зависимости из `requirements.txt` (`fastapi`, `uvicorn`, `numpy`, `scipy`, `pandas`, `plotly`)

### Установка:
```bash
pip install -r requirements.txt
```

### Запуск веб-интерфейса:
```bash
python run.py
```
Сервер запустится на `http://127.0.0.1:8000`.

### Пакетная генерация из командной строки:
```bash
python run.py --cli --n-models 10
```

### Запуск модульных тестов:
```bash
python -m unittest tests/test_all.py
```

## 3. Подробное руководство по веб-интерфейсу

### 3.1. Верхняя панель управления
| Элемент | Описание |
|---|---|
| **Переключатель темы (Солнце/Луна)** | Переключение между светлой и тёмной темами оформления с сохранением в `localStorage`. |
| **Кнопка «Экспорт ZIP»** | Скачивание единого ZIP-архива активного ансамбля со всеми колодами, CSV-таблицами и ML-массивами. |
| **Селектор «Модель»** | Переключение между синтетическими реализациями ансамбля (`SYNTH_001`, `SYNTH_002`...). |
| **Селектор «Свойство»** | Выбор активного поля: `PORO` (пористость), `PERMX`/`PERMY`/`PERMZ` (проницаемость), `NTG` (песчанистость). |
| **Ползунок «Слой»** | Выбор вертикального слоя по глубине $Z$ ($1 \dots 6$). |

### 3.2. Боковая панель параметров
| Параметр / Кнопка | Назначение |
|---|---|
| **Пресет коллектора** | Быстрая загрузка профиля: *Сбалансированный пласт*, *Слоистый с анизотропией*, *Русловый коллектор*, *Высокая неоднородность*. |
| **Число моделей** | Количество синтетических реализаций в генерируемом ансамбле ($1 \dots 50$). |
| **Радиус корреляции XY** | Латеральный радиус корреляции (в ячейках сетки). Задает горизонтальный масштаб фациальных зон. |
| **Связность по вертикали Z** | Вертикальный радиус корреляции (в слоях). Обеспечивает непрерывный переход свойств по толщине пласта. |
| **Дисперсия возмущения** | Степень случайного отклонения синтетического поля от базовой модели ($5\% \dots 60\%$). |
| **Связь пористости и проницаемости (R)** | Коэффициент корреляции между $\Phi$ и $\log(K)$ при ко-симуляции ($0.50 \dots 0.99$). |
| **Анизотропия Kz/Kh** | Отношение вертикальной проницаемости к латеральной ($0.01 \dots 0.50$). |
| **Селектор «Гидродинамика»** | Выбор решателя: встроенный 3D IMPES (0.1–0.2 с) или внешний OPM Flow (`flow`). |
| **Кнопка «Сгенерировать ансамбль»** | Старт расчета серии моделей с отображением прогресс-бара. |
| **Селектор «Активный ансамбль»** | Переключение между ранее сохраненными сериями генерации. |

### 3.3. Вкладки рабочей области
1. **Текстовые файлы (.DATA / .INC)**:
   - Проводник по файлам выбранной модели (`SYNTH_001.DATA`, `EX1_PORO.inc`, `EX1_PERMX.inc`, `SCHEDULRE.SCH` и др.);
   - Инспектор исходного кода с подсветкой и номерами строк;
   - Кнопки: «Копировать» в буфер, «Скачать файл» (отдельный текстовый файл), «Скачать модель (.ZIP)» (архив модели).
2. **2D Срезы**:
   - Послойное сравнение базового пласта и синтетической реализации на выбранной глубине;
   - Научная цветовая шкала Viridis с числовыми шкалами значений.
3. **3D Сетка**:
   - Интерактивный трехмерный куб пласта ($15 \times 15 \times 6$ ячеек);
   - Вращение, масштабирование, пространственный анализ зон повышенной проницаемости и коллекторских тел.
4. **Контроль качества (QC)**:
   - Метрики: рейтинг физической адекватности, непрерывность по Z, петрофизический $R$, средняя анизотропия;
   - 3D Вариограммы: графики полувариограмм $\gamma(h)$ по латерали и вертикали;
   - Кросс-плот: логарифмическая диаграмма $\Phi$ vs $\log_{10}(K)$ с линией регрессии.
5. **Добыча**:
   - Динамические кривые разработки 13 скважин: накопленный дебит нефти (FOPR) и обводненность продукции (FWCT).

## 4. Математический аппарат и реализация

### 4.1. 3D Спектральная геостатистика (GRF 3D FFT)
Генерация трехмерных случайных полей выполняется в спектральной области:
$$S(k_x, k_y, k_z) = \frac{1}{\left(1 + (k_x R_x)^2 + (k_y R_y)^2 + (k_z R_z)^2\right)^2}$$

Поле возмущений вычисляется через обратное трехмерное преобразование Фурье:
$$\Delta Z(x, y, z) = \operatorname{Re}\left(\mathcal{F}_{3D}^{-1} \left[ \sqrt{S(\mathbf{k})} \cdot W(\mathbf{k}) \right]\right)$$

Значение $R_z \ge 1.5$ гарантирует сглаженность и непрерывность геологических тел по вертикали.

### 4.2. Петрофизическая ко-симуляция
На основе калибровки по базовой колоде:
$$\log_{10}(K_x) = a \cdot \Phi + b + \varepsilon$$
Проницаемость $K_x$ генерируется в согласованной связке со сгенерированной пористостью с заданным коэффициентом корреляции $R$. Значения $K_y, K_z$ рассчитываются с учетом седиментационной анизотропии.

### 4.3. Гидродинамический расчет (3D IMPES)
- Численный решатель рассчитывает поле пластового давления неявным методом и перенос водонасыщенности явным методом;
- Приток флюидов к 13 скважинам рассчитывается по формуле Писмана;
- Скорость расчета: 0.1–0.2 с на реализацию.

## 5. Формат данных для машинного обучения

Файл `dataset_ml_features_targets.npz`:
```python
import numpy as np

data = np.load("output/ensemble_20261121_155048/dataset_ml_features_targets.npz")
poro = data["poro"]   # Входные тензоры: [N, 6, 15, 15]
permx = data["permx"] # [N, 6, 15, 15]
fopr = data["fopr"]   # Выходные кривые добычи: [N, Timesteps]
fwct = data["fwct"]   # Обводненность: [N, Timesteps]
```
Подходит для прямого использования в PyTorch / TensorFlow для обучения 3D CNN и суррогатных моделей.
