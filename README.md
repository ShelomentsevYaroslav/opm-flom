# OPM-Synth Studio: Генератор синтетических данных нефтяных месторождений

**OPM-Synth Studio** — программный комплекс для генерации трехмерных синтетических геолого-гидродинамических моделей нефтяных пластов и подготовки датасетов для обучения нейросетей (3D CNN, суррогатное моделирование, Physics-Informed ML).

Комплекс обеспечивает физически согласованное распределение фильтрационно-емкостных свойств (пористость, анизотропная проницаемость, песчанистость), сохранение вертикальной и латеральной непрерывности пласта, расчет динамики добычи двухфазной фильтрации и экспорт в стандартные колоды Eclipse / OPM Flow (`.DATA`, `.INC`) и массивы NumPy (`.npz`).

## 1. Установка и запуск

### Системные требования
- Python 3.9 или выше;
- ОС: Windows, Linux или macOS.

### Шаг 1. Клонирование репозитория и установка зависимостей
```bash
git clone https://github.com/ShelomentsevYaroslav/opm-flom.git
cd opm-flom
pip install -r requirements.txt
```

### Шаг 2. Запуск приложения

#### Интерактивный веб-интерфейс:
```bash
python run.py
```
Приложение запустит локальный веб-сервер и откроет интерфейс в браузере по адресу: **`http://127.0.0.1:8000`** (при занятости порта 8000 автоматически выбирается свободный порт).

*Дополнительные параметры запуска:*
- `--port 8080` — принудительный выбор порта;
- `--host 0.0.0.0` — доступ по локальной сети;
- `--no-browser` — запуск сервера без автоматического открытия вкладки браузера.

#### Пакетная генерация из консоли (CLI):
```bash
python run.py --cli --n-models 10
```
Выполняет расчет без запуска графической оболочки и сохраняет готовую серию в директорию `output/ensemble_<timestamp>/`.

#### Запуск модульных тестов:
```bash
python -m unittest tests/test_all.py
```
Выполняет 6 сквозных тестов: парсинг колод, 3D спектральная геостатистика, петрофизика, 3D IMPES фильтрация и валидация физических границ.

## 2. Руководство по веб-интерфейсу

Интерфейс спроектирован по модульному принципу: слева расположена панель управления параметрами, сверху — глобальные селекторы и экспорт, по центру — рабочая область с 5 вкладками.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  OPM-Synth Studio          [Модель: SYNTH_001] [Свойство: PORO] [Слой: 1]  ☼ │
├──────────────┬──────────────────────────────────────────────────────────────┤
│  ПАРАМЕТРЫ   │  [Файлы .DATA/.INC] [2D Срезы] [3D Сетка] [QC] [Добыча]      │
│  - Пресеты   ├──────────────────────────────────────────────────────────────┤
│  - Слайдеры  │                                                              │
│  - Запуск    │                  Рабочая область вкладки                     │
│  - Ансамбли  │                                                              │
└──────────────┴──────────────────────────────────────────────────────────────┘
```

### 2.1. Верхняя панель инструментов
- **Переключатель темы (иконка Солнце / Луна)** — мгновенное переключение между светлой и тёмной темами оформления. Выбранный режим автоматически сохраняется в браузере (`localStorage`).
- **Кнопка «Экспорт ZIP»** — архивирует текущий активный ансамбль и запускает скачивание полного архива со всеми колодами (`.DATA`, `.INC`), таблицами динамики скважин (`summary_production_curves.csv`) и ML-датасетом (`dataset_ml_features_targets.npz`).
- **Селектор «Модель»** — переключение между сгенерированными синтетическими реализациями ансамбля (`SYNTH_001`, `SYNTH_002` и т.д.).
- **Селектор «Свойство»** — выбор визуализируемого поля:
  - `PORO` — пористость пласта;
  - `PERMX`, `PERMY`, `PERMZ` — проницаемость по осям X, Y, Z (мД);
  - `NTG` — коэффициент песчанистости (Net-to-Gross).
- **Ползунок «Слой» ($1 \dots 6$)** — выбор текущего вертикального среза пласта по глубине для отображения на 2D картах.

---

### 2.2. Боковая панель параметров (слева)

#### Пресет коллектора (быстрый выбор)
Выпадающий список позволяет мгновенно загрузить откалиброванные геологические настройки:
- **Сбалансированный пласт** — средняя латеральная ($R_{xy}=4.0$) и вертикальная ($R_z=2.5$) связность, умеренная дисперсия ($25\%$), корреляция $R=0.90$;
- **Слоистый с анизотропией** — протяженные горизонтальные пласты ($R_{xy}=6.0$) с сильным вертикальным экранированием ($R_z=1.0$) и низкой вертикальной проницаемостью ($K_z/K_h = 0.05$);
- **Русловый коллектор** — вытянутые русловые песчаные тела ($R_{xy}=8.0, R_z=3.0$), повышенная петрофизическая связь ($R=0.92$);
- **Высокая неоднородность** — мелкий масштаб корреляции ($R_{xy}=3.0, R_z=1.5$) при высокой дисперсии возмущений ($45\%$).

#### Индивидуальные параметры генерации:
1. **Число моделей ($1 \dots 50$)** — объем формируемого ансамбля синтетических реализаций;
2. **Радиус корреляции XY ($1.0 \dots 10.0$ ячеек)** — пространственный масштаб неоднородностей в плоскости пласта. Высокие значения дают гладкие протяженные зоны, низкие — пятнистую мозаичную структуру;
3. **Связность по вертикали Z ($0.5 \dots 5.0$ слоев)** — радиус корреляции по глубине. Гарантирует непрерывность свойств между слоями пласта и устраняет искусственные межслойные разрывы;
4. **Дисперсия возмущения ($5\% \dots 60\%$)** — амплитуда случайных отклонений относительно базовой модели пласта;
5. **Связь пористости и проницаемости $R$ ($0.50 \dots 0.99$)** — сила петрофизической зависимости Козени-Кармана при генерации полей $K_x$;
6. **Анизотропия Kz/Kh ($0.01 \dots 0.50$)** — коэффициент отношения вертикальной проницаемости к латеральной;
7. **Гидродинамика (селектор решателя)**:
   - *Встроенный прокси (3D IMPES)* — мгновенный расчет фильтрации (0.1–0.2 с на реализацию) без сторонних утилит;
   - *OPM Flow (Внешний)* — промышленный гидродинамический расчет через симулятор `flow` (при наличии в системе).

#### Управление расчетом:
- **Кнопка «Сгенерировать ансамбль»** — запускает процесс генерации с отображением прогресс-бара;
- **Селектор «Активный ансамбль»** — список ранее сгенерированных серий расчетов с возможностью мгновенного переключения между ними.

---

### 2.3. Вкладки рабочей области

#### Вкладка 1: «Текстовые файлы (.DATA / .INC)»
Предназначена для детального аудита и выгрузки текстовых колод симулятора:
- **Дерево файлов модели (слева)** — список всех текстовых файлов выбранной модели (`SYNTH_001.DATA`, `EX1_PORO.inc`, `EX1_PERMX.inc`, `EX1_NTG.inc`, `SCHEDULRE.SCH`, `SUMMARY.INC`, `production.csv`, `summary_curves.json`) с указанием типов и объемов в КБ.
- **Инспектор кода (справа)** — окно с нумерацией строк и форматированным текстом выбранного файла.
- **Кнопка «Копировать»** — копирует содержимое файла в буфер обмена.
- **Кнопка «Скачать файл»** — скачивает выбранный текстовый файл на компьютер.
- **Кнопка «Скачать модель (.ZIP)»** — скачивает отдельный архив конкретной выбранной модели со всеми её файлами.

#### Вкладка 2: «2D Срезы»
- Отображает карты распределения выбранного свойства (пористость, проницаемость, песчанистость) для выбранного слоя пласта.
- Слева — базовая геологическая модель (`EX1`), справа — синтетическая реализация. Используется научная палитра Viridis с числовой цветовой шкалой.

#### Вкладка 3: «3D Сетка»
- Интерактивный объемный воксельный куб пласта ($15 \times 15 \times 6 = 1350$ расчетных ячеек).
- Поддерживает вращение левой кнопкой мыши, перемещение правой кнопкой и масштабирование колесиком. Позволяет визуально оценить трехмерную непрерывность коллектора.

#### Вкладка 4: «Контроль качества (QC)»
- **Карточки метрик**:
  - *QC Рейтинг* — интегральная оценка физической адекватности модели (0–100%);
  - *Связность по Z* — мера непрерывности свойств между смежными слоями пласта;
  - *Петрофизика ($R$)* — фактический коэффициент корреляции $\Phi$ и $\log(K)$;
  - *Анизотропия* — среднее значение $K_z / K_h$.
- **3D Вариограммы** — графики экспериментальных полувариограмм $\gamma(h)$ по латерали и вертикали, подтверждающие заданные радиусы корреляции.
- **Кросс-плот** — логарифмическая диаграмма зависимости пористости от проницаемости с линией регрессии.

#### Вкладка 5: «Добыча»
- Графики динамики разработки месторождения по 13 скважинам (10 добывающих, 3 нагнетательных):
  - **FOPR (Field Oil Production Rate)** — дебит нефти пласта во времени ($м^3/сут$);
  - **FWCT (Field Water Cut)** — динамика обводненности продукции ($0 \dots 1$).

## 3. Математический аппарат и методология

### 3.1. 3D Спектральная геостатистика
Для моделирования пространственной неоднородности пласта используется метод спектральной генерации гауссовских случайных полей (Gaussian Random Fields, GRF) на основе трехмерного быстрого преобразования Фурье (3D FFT).

1. В частотной области формируется пространственная спектральная плотность (фильтр Бесселя/Маттерна):
   $$S(k_x, k_y, k_z) = \frac{1}{\left(1 + (k_x R_x)^2 + (k_y R_y)^2 + (k_z R_z)^2\right)^2}$$
   где $R_x, R_y$ — латеральные радиусы корреляции (в ячейках сетки), $R_z$ — вертикальный радиус корреляции (в слоях).

2. Комплексный белый шум $W(\mathbf{k})$ фильтруется в частотной области и преобразуется в пространственную область обратным 3D FFT:
   $$\Delta Z(x, y, z) = \operatorname{Re}\left(\mathcal{F}_{3D}^{-1}\left[\sqrt{S(\mathbf{k})} \cdot W(\mathbf{k})\right]\right)$$

3. **Сохранение вертикальной связности**: благодаря трехмерной фильтрации со связностью $R_z \ge 1.5$ исключается искусственное расслоение пласта — свойства геологических тел плавно переходят через границы слоев сетки по глубине.

4. Для валидации поля рассчитывается экспериментальная полувариограмма:
   $$\hat{\gamma}(h) = \frac{1}{2 N(h)} \sum_{i=1}^{N(h)} \left(Z(u_i + h) - Z(u_i)\right)^2$$

---

### 3.2. Петрофизическая ко-симуляция ($\Phi \leftrightarrow K \leftrightarrow NTG$)
1. При инициализации система считывает базовую геологическую колоду (`data/baseline_deck/`) и оценивает параметры регрессионной связи:
   $$\log_{10}(K_x) = a \cdot \Phi + b + \varepsilon$$
2. Сгенерированное поле пористости $\Phi_{\text{synth}}$ используется для ко-симуляции проницаемости $K_x$ с заданным пользователем коэффициентом корреляции $R \in [0.5, 0.99]$.
3. Проницаемости по другим осям вычисляются с соблюдением законов седиментационной анизотропии:
   $$K_y = K_x \cdot \left(\frac{K_y}{K_x}\right)_{\text{base}}, \quad K_z = K_x \cdot \left(\frac{K_z}{K_x}\right)_{\text{target}} \cdot \exp(\varepsilon_z)$$
4. Коэффициент песчанистости $NTG$ согласуется с пористостью с учетом граничных отсечек коллектора.

---

### 3.3. Гидродинамическое моделирование (Dual-Engine)
1. **Встроенный 3D IMPES решатель (`engine/proxy_flow.py`)**:
   - Численно решает задачу двухфазной несжимаемой фильтрации (нефть + вода) в 3D сетке $15 \times 15 \times 6$;
   - Учитывает 13 скважин (добывающие $G1\dots G4, P1\dots P6$, нагнетательные $D1\dots D3$), размещенных в соответствии со схемой расписания `SCHEDULRE.SCH`;
   - Расчет дебитов выполняется по формуле Писмана с учетом фазовых проницаемостей;
   - Время расчета: **0.1–0.2 с** на реализацию на обычном CPU.
2. **Внешний симулятор OPM Flow (`engine/opm_runner.py`)**:
   - Автоматически проверяет наличие утилиты `flow` в системе;
   - Формирует команду запуска, отслеживает расчет и конвертирует стандартные результаты Eclipse (`.UNSMRY`, `.SMSPEC`).

## 4. Использование в машинном обучении (ML / PyTorch)

Каждый сгенерированный ансамбль сохраняет файл `dataset_ml_features_targets.npz`, содержащий готовые многомерные тензоры для прямого обучения нейросетей:

```python
import numpy as np

# Загрузка ML-датасета
dataset = np.load("output/ensemble_20261121_155048/dataset_ml_features_targets.npz")

# Входные 4D тензоры фильтрационно-емкостных свойств (формат: [N, Nz, Ny, Nx])
# N — число моделей, Nz=6 слоев, Ny=15, Nx=15
poro  = dataset["poro"]   # Пористость
permx = dataset["permx"]  # Проницаемость Kx (мД)
permy = dataset["permy"]  # Проницаемость Ky (мД)
permz = dataset["permz"]  # Проницаемость Kz (мД)
ntg   = dataset["ntg"]    # Песчанистость

# Выходные временные ряды добычи (формат: [N, Timesteps])
fopr  = dataset["fopr"]   # Накопленный дебит нефти пласта во времени
fwct  = dataset["fwct"]   # Динамика обводненности во времени

print(f"Форма тензора пористости: {poro.shape}")  # (N, 6, 15, 15)
print(f"Форма кривых дебита:      {fopr.shape}")  # (N, 30)
```

Массивы готовы для подачи в трехмерные сверточные сети (3D CNN), вариационные автоэнкодеры (VAE), диффузионные модели и суррогатные нейросетевые аппроксиматоры динамики пласта.

## 5. Структура проекта

```
opm-flom/
├── data/                        # Исходная геологическая модель
│   └── baseline_deck/           # Базовая Eclipse колода (HEAD_OF_MODEL_1.DATA и инклюды)
├── engine/                      # Математическое ядро комплекса
│   ├── deck_io.py               # Парсер и сериализатор колод Eclipse (.DATA, .INC)
│   ├── geostats.py              # 3D спектральная геостатистика (GRF 3D FFT, вариограммы)
│   ├── petrophysics.py          # Петрофизический ко-симулятор (Phi <-> Kx,y,z <-> NTG)
│   ├── proxy_flow.py            # Встроенный численный 3D IMPES симулятор
│   ├── opm_runner.py            # Обертка внешнего симулятора OPM Flow
│   └── validator.py             # Модуль контроля качества и физических критериев (QC)
├── output/                      # Каталог сгенерированных ансамблей (колоды, CSV, NPZ)
├── tests/                       # Пакет модульных и интеграционных тестов
│   └── test_all.py              # 6 сквозных тестов компонентов
├── web/                         # Веб-приложение
│   ├── app.py                   # Бэкенд на FastAPI (REST API, стриминг файлов и ZIP)
│   └── static/                  # Фронтенд (HTML, CSS, JS, Plotly.js)
├── generator.py                 # Оркестратор пакетной генерации и сборки датасетов
├── run.py                       # Единая точка запуска (веб-интерфейс / CLI)
└── requirements.txt             # Список Python-зависимостей
```
